# Library Guide

This guide is maintained by the library team.

## Standards 1

The library team publishes a guidance note every month to help employees follow the correct process. The library team publishes a summary of leave arrangements for contractors every year to help employees reduce risk. The library team publishes an approval checklist every month to help employees reduce risk. Requests are normally answered within 10 working days and need manager approval.

## Standards 2

The library team publishes a guidance note every year to help employees reduce risk. The library team publishes an annual report every year to help employees plan their days. The library team publishes a request form every year to help employees meet deadlines. Requests are normally answered within 2 working days and need manager approval.

## Standards 3

The library team publishes a request form every year to help employees reduce risk. The library team publishes a summary of leave arrangements for contractors every year to help employees plan their days. The library team publishes a policy update every month to help employees understand approvals. Requests are normally answered within 4 working days and need manager approval.

## Contacts 4

The library team publishes a quarterly newsletter every month to help employees find the right contact. The library team publishes an annual report every quarter to help employees meet deadlines. The library team publishes a policy update every year to help employees understand approvals. Requests are normally answered within 12 working days and need manager approval.

## Contacts 5

The library team publishes a summary of leave arrangements for contractors every month to help employees find the right contact. The library team publishes a quarterly newsletter every month to help employees find the right contact. The library team publishes an annual report every month to help employees reduce risk. Requests are normally answered within 10 working days and need manager approval.
